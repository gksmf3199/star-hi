Firebase 연결, 교사 권한 등록 & Firestore 보안 규칙 가이드

교사 권한 및 구글 로그인을 완전히 활성화하기 위해 아래 설정 절차를 진행하세요.

1. 내 Firebase 프로젝트 설정 연동 (옵션)

기본적으로 시뮬레이션 모드로 작동하지만, 직접 생성한 Firebase 프로젝트 설정을 적용할 수 있습니다.

2. 필수 Firestore Security Rules (보안 규칙)

Firebase 콘솔 → Firestore Database → Rules에 아래 코드를 그대로 붙여넣으세요.

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    
    // 교사 권한 확인 헬퍼 함수
    function isTeacher() {
      return request.auth != null &&
        exists(/databases/$(database)/documents/artifacts/stars-universe-edu/public/data/roles/$(request.auth.uid)) &&
        get(/databases/$(database)/documents/artifacts/stars-universe-edu/public/data/roles/$(request.auth.uid)).data.role == 'teacher';
    }

    // 역할(Roles) 컬렉션 규칙
    match /artifacts/stars-universe-edu/public/data/roles/{userId} {
      allow read: if request.auth != null;
      allow write: if false; // 보안상 Firebase 콘솔에서만 작성 가능
    }

    // 학생 등록 신청(Student Registrations) 컬렉션 규칙
    match /artifacts/stars-universe-edu/public/data/student_registrations/{userId} {
      allow read: if request.auth != null && (request.auth.uid == userId || isTeacher());
      allow create, update: if request.auth != null && (request.auth.uid == userId || isTeacher());
      allow delete: if isTeacher();
    }

    // 학생 제출 포스터(Posters) 컬렉션 규칙
    match /artifacts/stars-universe-edu/public/data/posters/{posterId} {
      allow read: if request.auth != null && (resource.data.studentUid == request.auth.uid || isTeacher());
      allow create: if request.auth != null;
      allow update, delete: if request.auth != null && (resource.data.studentUid == request.auth.uid || isTeacher());
    }

    // 교사 피드백(Feedbacks) 컬렉션 규칙
    match /artifacts/stars-universe-edu/public/data/feedbacks/{feedbackId} {
      allow read: if request.auth != null && (resource.data.studentUid == request.auth.uid || isTeacher());
      allow write: if isTeacher();
    }
  }
}

3. 클릭 순서별 Firebase 콘솔 직접 설정 방법

  1. Google 로그인 설정: Firebase 콘솔 접속 → Authentication → Sign-in method → Google 클릭 후 '사용 설정' 토글 ON.
  2. 승인된 도메인 등록: Authentication → Settings → Authorized domains → '도메인 추가' 클릭 → GitHub Pages 도메인(예: username.github.io) 입력 (https:// 제외).
  3. 교사 계정 수동 등록 (보안 핵심):
    ① 교사가 Google 로그인 후, Authentication의 사용자 목록에서 본인의 UID 복사.
    ② Firestore Database 생성 후 컬렉션 경로: /artifacts/stars-universe-edu/public/data/roles 생성.
    ③ 문서 ID에 교사 UID를 넣고 필드 추가: role: "teacher" (문자열).
